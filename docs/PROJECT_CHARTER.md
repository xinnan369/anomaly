# 项目章程

## 研究定位

VICAD-Syn 面向多视角、多光照条件下的工业视觉异常检测。研究数据集为 M²AD，重点关注 M²AD-Synergy 协议。Car、Cube、Doll、Ring 暂列为第一阶段候选，最终类别与数据设置以官方发布和审计证据为准。

## 技术假设与验证方向

DINOv2 ViT-B/14 是基础模型候选。以下四项均为待验证的研究假设。

| 待验证的研究假设 | 拟验证的问题 |
| --- | --- |
| 光照条件化特征预测 | 光照条件能否帮助区分正常光照变化与缺陷信号？ |
| 双上下文预测稳定性 | 双上下文是否能提高跨视角或跨光照条件下的预测稳定性？ |
| 预测不确定性建模 | 预测不确定性能否表征异常证据的可靠程度？ |
| 可靠性加权异常融合 | 根据可靠性加权能否改善多条件异常证据的融合？ |

## 资源与阶段

- 计划硬件为 NVIDIA RTX 3090 或 RTX 4090，均为 24 GB 显存。
- 预计研究周期为 2～3 个月。投稿目标为 SCI 二区优先、三区备选。
- 第一项待授权工作为 [数据集与实验协议审计](../instructions/TASK-001.md)。后续研究按独立任务授权推进。
- 实验设计须遵守官方评估协议，防止同一产品实例跨训练集和测试集泄漏，严禁用测试集标签训练或调参。
